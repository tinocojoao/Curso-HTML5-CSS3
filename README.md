# 🚀 Curso de HTML5 e CSS3 — Minha Jornada de Aprendizado

Este repositório foi criado para documentar e armazenar toda a minha evolução prática durante o curso de **HTML5 e CSS3**, ministrado pelo professor **Gustavo Guanabara** na plataforma **Curso em Vídeo**.

O objetivo aqui é registrar a base do meu aprendizado no desenvolvimento front-end, servindo como consulta rápida de estruturação semântica, estilização, design responsivo e boas práticas para a web.

---

## 👨‍🏫 Créditos e Reconhecimento

Todos os exercícios, páginas e desafios práticos contidos neste repositório foram desenvolvidos acompanhando o material do **Curso em Vídeo**.
